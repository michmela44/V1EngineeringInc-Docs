# Table Requirements

![LowRider v4 Top View](/img/lowrider/v4/Top.png)

Your table only needs to be as fancy as a sheet of wood on a relatively flat surface. A CNC machine
can self-correct many of its own imperfections. Stability is the main goal.

Any existing table large enough is fine. You can use it directly or add a replaceable waste board.
A simple 2×4 frame with MDF/plywood/OSB top is most common.

If you have a table saw or CNC, a torsion box table is easy and gives a very stable surface.

## Sizing

Use the [Size Calculator](/lowrider/build/calculator) to get the exact minimum table dimensions for
your build. These dimensions represent the belt holders flush with the outside corners — add 25–50 mm
(1–2 in) per side for comfortable clearance.

## Material Options

| Type | Notes |
|------|-------|
| MDF | Flat, cheap, heavy. Great spoilboard material. |
| Plywood / OSB | Lighter, good structural choice for the frame. |
| Torsion box | Very stable, good for precision work. |

The surface your work sits on (spoilboard) will eventually get cut into and needs to be replaced.
Plan for a sacrificial layer of MDF or similar that is easy to swap out.

## Community Table Plans

* ~$200–$400 basic table plans: [LR4 tables on the forum](https://forum.v1e.com/tag/parametric-table)

## Rail Mounting

The Y rail attaches to the table surface. A perfectly rectangular table is your reference — once the
rail is set, the machine squares to it. Spend time getting your table flat and square before mounting
anything.

See [Belt Installation](../build/assembly/belts) for the detailed rail and belt layout steps.

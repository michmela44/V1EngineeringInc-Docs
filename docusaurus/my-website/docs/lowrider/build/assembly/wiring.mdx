# Wire Routing

![Wire routing control board](/img/lowrider/v4/w1a.jpg)

* Find a good home for your control board. The YZ\_Min side (shown) is recommended.
* The first bay makes wiring easiest and gives good SD card access.
* [Jackpot Wiring](https://docs.v1e.com/electronics/jackpot/#wiring). Other boards will be similar.

---

![Wire routing YZ wires](/img/lowrider/v4/w1.jpg)

* Run wires from YZ assemblies to the beam with the beam at full height.
* Feed the wires from the YZ assembly into the beam and secure to the brace.
* Make sure travel is free, clear, and smooth — test by moving the beam up and down.
* Cable ties, wire ties, or tape to the braces work well.

---

![Wire routing extensions](/img/lowrider/v4/w2.jpg)

* Extensions are used from the YZ\_Max side and from the Core to reach the control board.
* Extension connections need to be secured to remove any strain.
* Fold the wires leaving the connection straight, then tape.

---

![Wire routing taped](/img/lowrider/v4/w3.jpg)

* Taping like this takes all strain off the connectors.
* Label the connection and the end of the extension.
* Repeat for Y1 and Z1 steppers and endstops, as well as the Core's X and X endstop.

---

![Wire routing bundled](/img/lowrider/v4/w4.jpg)

* Run all the way to the control board and plug in.
* Secure all wires at each brace. Pull all slack to the furthest section.

---

![Wire routing folded](/img/lowrider/v4/w5.jpg)

* Fold each wire up on itself, secure, and make a nice bundle.

---

![Wire routing extensions secured](/img/lowrider/v4/w5b.jpg)

* Extensions secured into place.
* Wires connected to the control board.
* You can run wires along the top (shown — helps with dust management) or along the bottom.

---

![Wire routing core wires](/img/lowrider/v4/w6.jpg)

* For most builds, bundling the wires with your Router power cord is easiest.
* If not using a vac hose or router, use some sort of wire loom or cover for rigidity. The "tape
  measure trick" will also work here.

---

![Wire routing core max](/img/lowrider/v4/w7.jpg)

* Move the core all the way to X\_Max (the YZ\_Max plate).
* Secure wires to the first position at the top of the Core.
* Add Hose\_Hooks to hold the wires — longer hooks go where the hose moves, short ones go on the
  middle and end brace.
* Leave a small loop in the wires at the max position; secure to the brace just past halfway.
* If using a router, set it in the tool mount and run the power cord along with the wires.

---

![Wire routing core midpoint](/img/lowrider/v4/w8.jpg)

* Core wires run to the halfway point, then into the braces with the other wires.
* Wire up to the control board and bundle neatly.
* Carefully ensure the Core reaches both ends without pulling on wires.
* A little partial twist in the wire bundle helps them behave when the core moves.

---

![Wire routing vac hose](/img/lowrider/v4/w8b.jpg)

* When adding the vacuum hose, connect it to your dust shoe and up to the second mounting hole
  in the top of the Core.
* Secure the hose to your middle brace and Hose Hook. Add a partial twist if needed so the hose
  tracks properly without falling over the front or back.
* Pass the wires under the hose at the middle position (not over — it can snag).
* Secure wires to the hose just after each hose hook.

---

![Wire routing test](/img/lowrider/v4/w8c.jpg)

* Test wire and hose routing at both extremes.
* This is much easier before the X belt is added.
* Take your time and get this tracking well.

---

![Wire routing YZ min wires](/img/lowrider/v4/w9.jpg)

* Run the YZ Min assembly wires.
* Slack can be bundled on either side of the board box.
* Leave the board box as open and uncluttered as possible for air flow.

---

![Wire routing board box](/img/lowrider/v4/w9b.jpg)

* Leave the board box as open for air flow as possible.

---

![Wire routing power supply](/img/lowrider/v4/w9c.jpg)

* After the strut plates are cut, the power supply will get mounted here.
* Size your wires to give yourself room to work.

---

![Wire routing power supply temp](/img/lowrider/v4/w9d.jpg)

* For now, flip the power supply to hold it in place on your hose hooks.
* When strut plates are done, this gets more permanently mounted.

---

![Wire routing extension cord](/img/lowrider/v4/w9e.jpg)

* **Bonus tip!** You can run a single extension cord into the beam rather than routing the power
  supply and router cords out with the vacuum hose. This makes Y motion cable management easier
  later and makes it easy to add an SSR for automated router control (advanced).

---

![Wire routing all done](/img/lowrider/v4/w9f.jpg)

* All wired up and ready to move on!

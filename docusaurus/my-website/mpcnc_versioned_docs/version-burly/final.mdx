# MPCNC Final Assembly

## Squaring

![final squaring 1](/img/old/2015/10/IMG_20151025_124732.jpg)

* Using the table as a straight guide screw down any two feet.
* Pre-drilling is recommended.

---

![final squaring 2](/img/old/2015/10/IMG_20151025_131236.jpg)
![final squaring 3](/img/old/2015/10/IMG_20151025_131308.jpg)

* Measure across the center both ways, make the dimension as equal as you can.
* Clamp down the feet before you screw them down, pre-drilling really helps here. Do one foot then the next. Clamp, drill screw.
* **This is a critical measurement**, if this is too far off you will cut parallelograms instead of squares.

---

![final leg height](/img/old/2015/10/IMG_20151025_131825.jpg)

* Either measure or use a block (or socket and extension) to set all the legs to the same height.
* Lightly snug up the Feet screws and the lock screws.

:::tip Pro tip
If you were careful with your leg cuts, this can be a very easy step…
:::

---

## Running the Wires

* Decide where your control board will be located.

![wiring 1](/img/old/2015/10/IMG_20160823_134126.jpg)

* Run the wire through the rail to the stepper furthest from the control board and secure with a cable tie to the plate. (I chose to cover the wires with PET braiding on this build).
* Make sure the belt will have a clear path.

![wiring 2](/img/old/2015/10/IMG_20160823_135523.jpg)

* For the Series wiring harness, connect the closer stepper to the plug in the middle of the harness with these steppers I match the pin side or non-pin side of the plugs. For the "Individual/dual endstop" wiring harness, run each wire all the way from each stepper to the control board.

![wiring 3](/img/old/2015/10/IMG_20160823_135543.jpg)
![wiring 4](/img/old/2018/05/IMG_20180529_1806062.jpg)

* Secure all connections with tape as shown in both pictures. Tape the connection, then fold and tape again.

:::warning
You don't want any stepper wires to come loose while running. It will probably ruin the project and might ruin the motor driver.
:::
